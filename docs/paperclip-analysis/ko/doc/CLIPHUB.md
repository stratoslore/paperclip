# ClipHub — 회사 레지스트리

**회사를 다운로드하세요.**

ClipHub는 사람들이 Paperclip 회사 구성을 공유하고, 탐색하고, 다운로드할 수 있는 공개 레지스트리입니다. 회사 템플릿은 전체 조직 — 에이전트, 보고 구조, 어댑터 설정, 역할 정의, 시드 작업 — 을 포함하는 이식 가능한 아티팩트로, 하나의 명령어로 바로 실행할 수 있습니다.

---

## 개요

ClipHub는 프로그래밍 언어에서의 패키지 레지스트리와 같은 역할을 Paperclip에 대해 수행합니다. Paperclip은 이미 내보내기 가능한 조직 구성을 지원합니다([SPEC.md](./SPEC.md) §2 참조). ClipHub는 이러한 내보내기가 저장되는 공개 디렉터리입니다.

사용자가 Paperclip에서 작동하는 회사를 구축하고 — 개발 회사, 마케팅 에이전시, 연구소, 콘텐츠 스튜디오 — 템플릿을 내보내 ClipHub에 게시합니다. 누구든지 자신의 Paperclip 인스턴스에서 해당 회사를 탐색, 검색, 다운로드하여 실행할 수 있습니다.

태그라인: **말 그대로 회사를 다운로드할 수 있습니다.**

---

## 게시되는 내용

ClipHub 패키지는 **회사 템플릿 내보내기** — Paperclip 스펙에 정의된 이식 가능한 아티팩트 형식입니다. 다음을 포함합니다:

| 구성 요소 | 설명 |
|---|---|
| **회사 메타데이터** | 이름, 설명, 용도, 카테고리 |
| **조직도** | 전체 보고 계층 구조 — 누가 누구에게 보고하는지 |
| **에이전트 정의** | 모든 에이전트: 이름, 역할, 직함, 역량 설명 |
| **어댑터 설정** | 에이전트별 어댑터 유형 및 구성 (SOUL.md, HEARTBEAT.md, CLAUDE.md, 프로세스 명령, 웹훅 URL — 어댑터에 필요한 모든 것) |
| **시드 작업** | 회사의 첫 실행을 부트스트랩하기 위한 선택적 시작 작업 및 이니셔티브 |
| **예산 기본값** | 에이전트별 및 회사별 권장 토큰/비용 예산 |

템플릿은 **구조이지 상태가 아닙니다.** 진행 중인 작업, 과거 비용 데이터, 런타임 아티팩트는 포함되지 않습니다. 오직 설계도만 있습니다.

### 서브 패키지

모든 사용 사례에 전체 회사가 필요한 것은 아닙니다. ClipHub는 개별 구성 요소의 게시도 지원합니다:

- **에이전트 템플릿** — 단일 에이전트 구성 (예: "Senior TypeScript Engineer", "SEO Content Writer", "DevOps Agent")
- **팀 템플릿** — 조직도의 하위 트리 (예: "마케팅 팀: CMO + 3명의 보고자", "엔지니어링 포드: 테크 리드 + 4명의 엔지니어")
- **어댑터 설정** — 특정 에이전트 역할과 무관한 재사용 가능한 어댑터 구성

이들은 기존 회사에 혼합하여 사용할 수 있습니다. 에이전트를 다운로드하고, 조직에 배치하고, 관리자를 지정하면 끝입니다.

## 핵심 기능

### 탐색 및 발견

홈페이지는 여러 차원에서 회사를 보여줍니다:

- **추천** — 에디터가 선별한 고품질 템플릿
- **인기** — 다운로드, 별점, 포크 수 기준 순위
- **최신** — 최근 게시 또는 업데이트된 항목
- **카테고리** — 용도별 탐색 (아래 카테고리 참조)

각 목록에는 이름, 간략한 설명, 조직 규모(에이전트 수), 카테고리, 사용된 어댑터 유형, 별점 수, 다운로드 수, 미니 조직도 미리보기가 표시됩니다.

### 검색

검색은 **키워드만이 아닌 의미 기반입니다.** 벡터 임베딩을 사용하여 의도로 검색할 수 있습니다:

- "marketing agency that runs facebook ads" → 해당 단어가 제목에 없더라도 관련 회사 템플릿을 찾습니다
- "small dev team for building APIs" → 소규모 엔지니어링 조직을 찾습니다
- "content pipeline with writers and editors" → 콘텐츠 스튜디오 템플릿을 찾습니다

카테고리, 에이전트 수 범위, 어댑터 유형, 별점 수, 최신순 필터링도 지원합니다.

### 회사 상세 페이지

회사 템플릿을 클릭하면 다음이 표시됩니다:

- **전체 설명** — 이 회사가 무엇을 하는지, 어떻게 운영되는지, 무엇을 기대할 수 있는지
- **인터랙티브 조직도** — 역할, 직함, 역량이 포함된 모든 에이전트의 시각적 트리
- **에이전트 목록** — 각 에이전트의 확장 가능한 세부 정보 (어댑터 유형, 구성 요약, 역할 설명)
- **시드 작업** — 포함된 시작 이니셔티브 및 작업
- **예산 개요** — 권장 비용 구조
- **설치 명령어** — 다운로드 및 생성을 위한 한 줄 CLI 명령어
- **버전 기록** — 변경 로그, 시맨틱 버전, 이전 버전 사용 가능
- **커뮤니티** — 별점, 댓글, 포크 수

### 설치 및 포크

템플릿을 사용하는 두 가지 방법:

**설치 (새로 시작):**
```
paperclip install cliphub:<publisher>/<company-slug>
```
템플릿을 다운로드하고 로컬 Paperclip 인스턴스에 새 회사를 생성합니다. 자신의 API 키를 추가하고, 예산을 설정하고, 에이전트를 커스터마이즈한 후 실행하면 됩니다.

**포크:**
포크는 자신의 ClipHub 계정 아래에 템플릿 사본을 생성합니다. 이를 수정하고, 자신의 변형으로 재게시할 수 있으며, 포크 계보가 추적됩니다. 이를 통해 진화적 개선이 가능합니다 — 누군가 마케팅 에이전시를 게시하면, 이를 포크하고, 소셜 미디어 팀을 추가하고, 재게시할 수 있습니다.

### 별점 및 댓글

- **별점** — 북마크 및 품질 신호. 별점 수는 주요 순위 신호입니다.
- **댓글** — 각 목록에 대한 스레드 토론. 질문하고, 결과를 공유하고, 개선을 제안하세요.

### 다운로드 수 및 신호

모든 설치가 집계됩니다. 레지스트리는 다음을 추적합니다:

- 총 다운로드 수 (전체 기간)
- 버전별 다운로드 수
- 포크 수
- 별점 수

이러한 신호는 검색 순위 및 발견에 반영됩니다.

## 게시

### 게시할 수 있는 사람

GitHub 계정이 있는 누구나 ClipHub에 게시할 수 있습니다. 인증은 GitHub OAuth를 통해 이루어집니다.

### 게시 방법

Paperclip 내에서 회사를 템플릿으로 내보낸 후 게시합니다:

```
paperclip export --template my-company
paperclip publish cliphub my-company
```

또는 웹 UI를 사용하여 템플릿 내보내기를 직접 업로드할 수 있습니다.

### 제공해야 하는 정보

게시할 때 다음을 지정합니다:

| 필드 | 필수 | 설명 |
|---|---|---|
| `slug` | 예 | URL에 안전한 식별자 (예: `lean-dev-shop`) |
| `name` | 예 | 표시 이름 |
| `description` | 예 | 이 회사가 무엇을 하고 누구를 위한 것인지 |
| `category` | 예 | 기본 카테고리 (아래 참조) |
| `tags` | 아니오 | 탐색을 위한 추가 태그 |
| `version` | 예 | 시맨틱 버전 (예: `1.0.0`) |
| `changelog` | 아니오 | 이 버전에서 변경된 내용 |
| `readme` | 아니오 | 확장 문서 (마크다운) |
| `license` | 아니오 | 사용 조건 |

### 버전 관리

템플릿은 시맨틱 버전 관리를 사용합니다. 각 게시는 불변의 버전을 생성합니다. 사용자는 어떤 버전이든 설치하거나 기본적으로 `latest`를 사용할 수 있습니다. 버전 기록 및 변경 로그는 상세 페이지에서 확인할 수 있습니다.

### `sync` 명령어

여러 템플릿을 관리하는 고급 사용자를 위해:

```
paperclip cliphub sync
```

로컬에 내보낸 템플릿을 스캔하고 새로 추가되었거나 업데이트된 템플릿을 게시합니다. 단일 저장소에서 회사 템플릿 포트폴리오를 관리할 때 유용합니다.

## 카테고리

회사 템플릿은 용도별로 분류됩니다:

| 카테고리 | 예시 |
|---|---|
| **소프트웨어 개발** | 풀스택 개발 회사, API 개발 팀, 모바일 앱 스튜디오 |
| **마케팅 및 성장** | 퍼포먼스 마케팅 에이전시, 콘텐츠 마케팅 팀, SEO 회사 |
| **콘텐츠 및 미디어** | 콘텐츠 스튜디오, 팟캐스트 제작, 뉴스레터 운영 |
| **연구 및 분석** | 시장 조사 회사, 경쟁 정보, 데이터 분석 팀 |
| **운영** | 고객 지원 조직, 내부 운영 팀, QA/테스트 회사 |
| **영업** | 아웃바운드 영업 팀, 리드 생성, 계정 관리 |
| **재무 및 법무** | 회계 서비스, 컴플라이언스 모니터링, 재무 분석 |
| **크리에이티브** | 디자인 에이전시, 카피라이팅 스튜디오, 브랜드 개발 |
| **범용** | 스타터 템플릿, 최소 조직, 단일 에이전트 설정 |

카테고리는 배타적이지 않습니다 — 템플릿은 하나의 기본 카테고리에 교차 관심사를 위한 태그를 추가할 수 있습니다.

## 운영 및 신뢰

### 인증된 게시자

특정 기준을 충족하는 게시자(계정 기간, 좋은 신호를 가진 게시 템플릿)는 인증 배지를 받습니다. 인증된 템플릿은 검색에서 더 높은 순위를 차지합니다.

### 보안 검토

회사 템플릿에는 실행 가능한 명령(프로세스 어댑터)이나 웹훅 URL(HTTP 어댑터)이 포함될 수 있는 어댑터 구성이 포함되어 있습니다. 운영 시스템:

1. **자동 스캔** — 어댑터 구성에서 의심스러운 패턴(임의 코드 실행, 데이터 유출 URL, 자격 증명 수집)을 검사
2. **커뮤니티 신고** — 로그인한 사용자는 누구나 템플릿을 신고할 수 있습니다. 다수의 신고가 접수되면 검토 대기 중 자동 숨김 처리
3. **수동 검토** — 운영자가 승인, 거부, 또는 변경 요청 가능

### 계정 제한

새 계정은 게시하기 전에 대기 기간이 있습니다. 이는 일회성 스팸을 방지합니다.

## 아키텍처

ClipHub는 Paperclip 자체와는 **별도의 서비스**입니다. Paperclip은 자체 호스팅되고, ClipHub는 Paperclip 인스턴스와 통신하는 호스팅된 레지스트리입니다.

### 통합 지점

| 레이어 | 역할 |
|---|---|
| **ClipHub Web** | 탐색, 검색, 발견, 댓글, 별점 — 웹사이트 |
| **ClipHub API** | 프로그래밍 방식으로 게시, 다운로드, 검색하기 위한 레지스트리 API |
| **Paperclip CLI** | `paperclipai install`, `paperclipai publish`, `paperclipai cliphub sync` — Paperclip에 내장 |
| **Paperclip UI** | 앱을 벗어나지 않고 템플릿을 탐색하기 위한 Paperclip 웹 UI의 "ClipHub 탐색" 패널 |

### 기술 스택

| 레이어 | 기술 |
|---|---|
| 프론트엔드 | React + Vite (Paperclip과 동일) |
| 백엔드 | TypeScript + Hono (Paperclip과 동일) |
| 데이터베이스 | PostgreSQL |
| 검색 | 의미 검색을 위한 벡터 임베딩 |
| 인증 | GitHub OAuth |
| 스토리지 | 오브젝트 스토리지(S3 또는 동등)에 저장된 템플릿 zip 파일 |

### 데이터 모델 (스케치)

```
Publisher
  id, github_id, username, display_name, verified, created_at

Template
  id, publisher_id, slug, name, description, category,
  tags[], readme, license, created_at, updated_at,
  star_count, download_count, fork_count,
  forked_from_id (nullable)

Version
  id, template_id, version (semver), changelog,
  artifact_url (zip), agent_count, adapter_types[],
  created_at

Star
  id, publisher_id, template_id, created_at

Comment
  id, publisher_id, template_id, body, parent_id (nullable),
  created_at, updated_at

Report
  id, reporter_id, template_id, reason, created_at
```

## 사용자 흐름

### "회사를 시작하고 싶어요"

1. ClipHub를 열고, 카테고리별로 탐색하거나 "dev shop for building SaaS"를 검색
2. 맞는 템플릿을 찾기 — "Lean SaaS Dev Shop (CEO + CTO + 3 Engineers)"
3. 설명을 읽고, 조직도를 살펴보고, 댓글을 확인
4. `paperclipai install cliphub:acme/lean-saas-shop` 실행
5. Paperclip이 모든 에이전트가 사전 구성된 회사를 로컬에 생성
6. API 키를 설정하고, 예산을 조정하고, 초기 작업을 추가
7. 실행

### "훌륭한 것을 만들었고 공유하고 싶어요"

1. Paperclip에서 잘 작동할 때까지 회사를 구축하고 반복
2. 내보내기: `paperclipai export --template my-agency`
3. 게시: `paperclipai publish cliphub my-agency`
4. 웹 UI에서 설명, 카테고리, 태그 입력
5. 템플릿이 라이브 — 다른 사람들이 찾아서 설치 가능

### "다른 사람의 회사를 개선하고 싶어요"

1. ClipHub에서 필요한 것에 가까운 템플릿을 찾기
2. 자신의 계정으로 포크
3. 포크를 로컬에 설치하고, 조직을 수정 (에이전트 추가, 구성 변경, 팀 재구성)
4. 자신의 변형으로 내보내기 및 재게시
5. 원본과 자신의 버전 모두에서 포크 계보가 표시

### "전체 회사가 아닌 훌륭한 에이전트 하나만 필요해요"

1. ClipHub에서 에이전트 템플릿 검색: "senior python engineer"
2. 별점이 높은 에이전트 구성 찾기
3. 해당 에이전트만 설치: `paperclipai install cliphub:acme/senior-python-eng --agent`
4. 기존 회사의 관리자에 배정
5. 완료

## Paperclip과의 관계

ClipHub는 Paperclip을 사용하는 데 **필수가 아닙니다.** ClipHub를 전혀 사용하지 않고도 처음부터 회사를 완전히 구축할 수 있습니다. 그러나 ClipHub는 진입 장벽을 극적으로 낮춥니다:

- **신규 사용자**는 몇 시간이 아닌 몇 분 만에 작동하는 회사를 얻습니다
- **숙련된 사용자**는 검증된 구성을 커뮤니티와 공유합니다
- **생태계**는 복리로 성장합니다 — 좋은 템플릿 하나하나가 다음 회사를 더 쉽게 만들어줍니다

ClipHub는 언어 런타임에 대한 패키지 레지스트리와 같은 존재입니다: 선택 사항이지만, 혁신적입니다.

## V1 범위

### 필수 기능

- [ ] 템플릿 게시 (CLI 또는 웹을 통한 업로드)
- [ ] 템플릿 탐색 (목록, 카테고리별 필터)
- [ ] 템플릿 상세 페이지 (설명, 조직도, 에이전트 목록, 설치 명령어)
- [ ] 의미 검색 (벡터 임베딩)
- [ ] `paperclipai install cliphub:<publisher>/<slug>` CLI 명령어
- [ ] GitHub OAuth 인증
- [ ] 별점
- [ ] 다운로드 수
- [ ] 버전 관리 (시맨틱 버전, 버전 기록)
- [ ] 기본 운영 (커뮤니티 신고, 자동 숨김)

### V2

- [ ] 댓글 / 스레드 토론
- [ ] 계보 추적이 포함된 포크
- [ ] 에이전트 및 팀 서브 패키지
- [ ] 인증된 게시자 배지
- [ ] 어댑터 구성의 자동 보안 스캔
- [ ] Paperclip 웹 UI의 "ClipHub 탐색" 패널
- [ ] 대량 게시를 위한 `paperclipai cliphub sync`
- [ ] 게시자 프로필 및 포트폴리오

### 범위 외

- 유료 / 프리미엄 템플릿 (적어도 초기에는 모든 것이 무료이고 공개)
- 프라이빗 레지스트리 (향후 엔터프라이즈 기능이 될 수 있음)
- ClipHub에서 회사 실행 (레지스트리이지 런타임이 아님 — Paperclip 자체의 철학과 일치)

# 무엇인가

Paperclip은 비즈니스를 운영하기 위해 에이전트 팀을 조율하는 Node 서버 및 UI입니다.

자체 에이전트를 연결하고, 목표를 할당하고, 에이전트의 작업과 비용을 추적하세요.

태스크 매니저처럼 보이지만 전문화된 기능과 에이전트 조율 기능이 있습니다.

**높은 수준의 감각으로 만들어졌으며, 사용감이 좋습니다**

# Paperclip이 적합한 경우:

- 자율 기업을 구축하고 싶은 경우
- 다양한 유형의 에이전트(OpenClaw, Codex, Claude, Cursor 등)를 공통 목표를 향해 협업하도록 조율하고 싶은 경우
- 20개의 Claude Code 터미널을 동시에 열어두고 있어서 누가 무엇을 하고 있는지 파악이 어려운 경우
- 에이전트가 24시간 자율적으로 실행되길 원하지만, 작업을 감사하고 필요할 때 개입하고 싶은 경우
- 비용을 모니터링하고 싶은 경우
- 태스크 매니저를 사용하는 것처럼 에이전트를 관리하는 프로세스를 원하는 경우
- 휴대폰에서 자율 비즈니스를 관리하고 싶은 경우

# Paperclip

**Paperclip은 자율 경제의 근간입니다.** 우리는 자율 AI 회사가 운영되는 인프라를 구축하고 있습니다. 우리의 목표는 Paperclip 기반 회사들이 집합적으로 세계 최대 국가들의 GDP에 필적하는 경제적 산출을 생성하는 것입니다. 모든 의사 결정은 이를 위해 이루어져야 합니다: 자율 회사를 더 유능하고, 더 통제 가능하고, 더 확장 가능하고, 더 실질적으로 만드는 것.

## 비전

자율 회사 — 실제 구조, 거버넌스, 책임을 갖춘 AI 인력 — 는 글로벌 경제에서 주요 세력이 될 것입니다. 하나의 회사가 아닙니다. 수천, 수백만 개입니다. Paperclip을 통해 조율되는 AI 노동력으로 운영되는 하나의 경제 계층 전체입니다.

Paperclip은 회사가 아닙니다. Paperclip은 회사를 가능하게 하는 것입니다. 우리는 컨트롤 플레인이자, 신경계이자, 운영 레이어입니다. 모든 자율 회사에는 구조, 작업 관리, 비용 통제, 목표 정렬, 인간 거버넌스가 필요합니다. 그것이 바로 우리입니다. 우리는 인간 기업에 대한 기업 운영 체제와 같은 존재입니다 — 다만 이번에는 운영 체제가 비유가 아닌 실제 소프트웨어입니다.

우리 성공의 척도는 하나의 회사가 작동하는지 여부가 아닙니다. Paperclip이 자율 회사가 구축되는 기본 기반이 되는지 여부이며, 그 회사들이 집합적으로 국가의 산출에 필적하는 심각한 경제적 세력이 되는지 여부입니다.

## 문제

작업 관리 소프트웨어는 충분하지 않습니다. 전체 인력이 AI 에이전트인 경우, 할 일 목록 이상의 것이 필요합니다 — 전체 회사를 위한 **컨트롤 플레인**이 필요합니다.

## 이것이 무엇인가

Paperclip은 AI 에이전트 회사를 위한 지휘, 통신, 제어 플레인입니다. 다음을 수행하는 단일 장소입니다:

- **에이전트를 직원으로 관리** — 누가 무엇을 하는지 채용, 조직, 추적
- **조직 구조 정의** — 에이전트가 스스로 운영하는 조직도
- **실시간 작업 추적** — 모든 에이전트가 무엇을 하고 있는지 언제든 확인
- **비용 통제** — 에이전트별 토큰 급여 예산, 지출 추적, 소진율
- **목표 정렬** — 에이전트가 자신의 작업이 더 큰 미션에 어떻게 기여하는지 확인
- **회사 지식 저장** — 조직을 위한 공유 브레인

## 아키텍처

두 개의 레이어:

### 1. 컨트롤 플레인 (이 소프트웨어)

중앙 신경계. 다음을 관리합니다:

- 에이전트 레지스트리 및 조직도
- 작업 배정 및 상태
- 예산 및 토큰 지출 추적
- 회사 지식 베이스
- 목표 계층 (회사 → 팀 → 에이전트 → 작업)
- 하트비트 모니터링 — 에이전트가 살아 있는지, 유휴 상태인지, 멈춰 있는지 파악

### 2. 실행 서비스 (어댑터)

에이전트는 외부에서 실행되고 컨트롤 플레인에 보고합니다. 에이전트는 실행되어 작업을 수행하는 Python 코드일 뿐입니다. 어댑터는 다양한 실행 환경을 연결합니다:

- **OpenClaw** — 초기 어댑터 대상
- **하트비트 루프** — 루프를 돌며 체크인하고 작업을 수행하는 간단한 커스텀 Python
- **기타** — API를 호출할 수 있는 모든 런타임

컨트롤 플레인은 에이전트를 실행하지 않습니다. 조율합니다. 에이전트는 어디에서든 실행되고 보고합니다.

## 핵심 원칙

Paperclip을 보면 전체 회사를 한눈에 이해할 수 있어야 합니다 — 누가 무엇을 하고 있는지, 비용이 얼마나 드는지, 제대로 작동하고 있는지.

# 이슈 워크트리 지원

상태: 실험적, 런타임 전용, 아직 사용자 대면 기능으로 출시하지 않음.

이 브랜치는 이슈 범위 워크트리에 필요한 런타임 및 시딩 작업을 포함합니다:

- 프로젝트 실행 워크스페이스 정책 지원
- 이슈 수준 실행 워크스페이스 설정
- 격리된 이슈 실행을 위한 git 워크트리 구현
- 선택적 명령 기반 워크트리 프로비저닝
- 시크릿 키 호환성을 위한 시딩된 워크트리 수정
- 현재 git 워크트리에 대한 시딩된 프로젝트 워크스페이스 재바인딩

아직 이 기능의 UI를 출시하지 않을 계획입니다. 런타임 코드는 유지되지만, 주요 UI 진입점은 현재 의도적으로 차단되어 있습니다.

## 현재 동작하는 것

- 프로젝트가 백엔드에서 실행 워크스페이스 정책을 가질 수 있음
- 이슈가 백엔드에서 실행 워크스페이스 설정을 가질 수 있음
- 하트비트 실행이 격리된 git 워크트리를 구현할 수 있음
- 런타임이 파생된 워크트리 내에서 프로젝트 정의 프로비전 명령을 실행할 수 있음
- 시딩된 워크트리 인스턴스가 로컬 암호화 시크릿을 정상 작동시킬 수 있음
- 시딩된 워크트리 인스턴스가 동일 저장소 프로젝트 워크스페이스 경로를 현재 git 워크트리로 재바인딩할 수 있음

## 숨겨진 UI 진입점

현재 의도적으로 비활성화된 이 기능의 사용자 대면 UI 표면:

- 프로젝트 설정:
  - `ui/src/components/ProjectProperties.tsx`
  - 실행 워크스페이스 정책 컨트롤
  - git 워크트리 기본 ref / 브랜치 템플릿 / 상위 디렉터리
  - 프로비전 / 해제 명령 입력

- 이슈 생성:
  - `ui/src/components/NewIssueDialog.tsx`
  - 격리된 이슈 체크아웃 토글
  - 프로젝트 정책에서 이슈 실행 워크스페이스 설정 기본값 적용

- 이슈 편집:
  - `ui/src/components/IssueProperties.tsx`
  - 이슈 수준 워크스페이스 모드 토글
  - 프로젝트 변경 시 이슈 실행 워크스페이스 설정 기본값 적용

- 에이전트/런타임 설정:
  - `ui/src/adapters/runtime-json-fields.tsx`
  - 런타임 서비스 JSON 필드, 더 넓은 워크스페이스-런타임 지원 표면의 일부

## UI가 숨겨진 이유

- 런타임 동작이 아직 검증 중
- 워크플로와 운영자 사용성이 최종 확정되지 않음
- 이슈, 프로젝트, 설정에서 부분적으로 완성된 사용자 대면 기능을 노출하고 싶지 않음

## 재활성화 계획

이것이 출시 준비가 되면:

- 위 파일들에서 차단된 UI 섹션을 재활성화
- 프로젝트 및 이슈 컨트롤의 문구와 기본값 검토
- 어떤 에이전트/런타임 설정을 고급 전용으로 유지할지 결정
- 전체 UI 워크플로에 대한 엔드투엔드 제품 수준 검증 추가

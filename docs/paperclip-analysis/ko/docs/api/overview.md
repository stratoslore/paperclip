Paperclip은 모든 컨트롤 플레인 작업을 위한 RESTful JSON API를 제공합니다.

## 기본 URL

기본값: `http://localhost:3100/api`

모든 엔드포인트는 `/api`로 시작합니다.

## 인증

모든 요청에는 `Authorization` 헤더가 필요합니다:

```
Authorization: Bearer <token>
```

토큰 유형:

- **에이전트 API 키** -- 에이전트용으로 생성된 장기 키
- **에이전트 실행 JWT** -- 하트비트 중 주입되는 단기 토큰 (`PAPERCLIP_API_KEY`)
- **사용자 세션 쿠키** -- 웹 UI를 사용하는 이사회 운영자용

## 요청 형식

- 모든 요청 본문은 `Content-Type: application/json`인 JSON입니다
- 회사 범위 엔드포인트는 경로에 `:companyId`가 필요합니다
- 실행 감사 추적: 하트비트 중 모든 변경 요청에 `X-Paperclip-Run-Id` 헤더를 포함하세요

## 응답 형식

모든 응답은 JSON을 반환합니다. 성공 응답은 엔티티를 직접 반환합니다. 오류 응답은 다음과 같습니다:

```json
{
  "error": "Human-readable error message"
}
```

## 오류 코드

| 코드 | 의미 | 조치 |
|------|---------|------------|
| `400` | 유효성 검사 오류 | 요청 본문을 예상 필드와 대조하세요 |
| `401` | 미인증 | API 키가 누락되었거나 유효하지 않습니다 |
| `403` | 권한 없음 | 이 작업에 대한 권한이 없습니다 |
| `404` | 찾을 수 없음 | 엔티티가 존재하지 않거나 사용자의 회사에 없습니다 |
| `409` | 충돌 | 다른 에이전트가 작업을 소유하고 있습니다. 다른 작업을 선택하세요. **재시도하지 마세요.** |
| `422` | 의미적 위반 | 유효하지 않은 상태 전환 (예: backlog -> done) |
| `500` | 서버 오류 | 일시적 장애입니다. 작업에 댓글을 달고 다음으로 넘어가세요. |

## 페이지네이션

목록 엔드포인트는 해당되는 경우 표준 페이지네이션 쿼리 파라미터를 지원합니다. 이슈는 우선순위별로, 기타 엔티티는 생성 날짜별로 정렬됩니다.

## 속도 제한

로컬 배포에서는 속도 제한이 적용되지 않습니다. 프로덕션 배포에서는 인프라 수준에서 속도 제한을 추가할 수 있습니다.

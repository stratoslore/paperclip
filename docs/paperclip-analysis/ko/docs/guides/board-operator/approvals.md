---
title: 승인
summary: 채용 및 전략을 위한 거버넌스 흐름
---

Paperclip에는 사람인 이사회 운영자가 주요 결정을 통제할 수 있도록 하는 승인 게이트가 포함되어 있습니다.

## 승인 유형

### 에이전트 채용

에이전트(일반적으로 매니저 또는 CEO)가 새로운 부하를 채용하려 할 때, 채용 요청을 제출합니다. 이렇게 하면 승인 대기열에 `hire_agent` 승인이 생성됩니다.

승인에는 제안된 에이전트의 이름, 역할, 역량, 어댑터 구성, 예산이 포함됩니다.

### CEO 전략

CEO의 초기 전략 계획은 CEO가 작업을 `in_progress`로 이동하기 전에 이사회 승인이 필요합니다. 이를 통해 회사 방향에 대한 사람의 승인을 보장합니다.

## 승인 워크플로

```
pending -> approved
        -> rejected
        -> revision_requested -> resubmitted -> pending
```

1. 에이전트가 승인 요청을 생성합니다
2. UI의 Approvals 페이지에서 승인 대기열에 표시됩니다
3. 요청 세부 사항과 연결된 이슈를 검토합니다
4. 다음 중 하나를 선택할 수 있습니다:
   - **승인** -- 해당 작업이 진행됩니다
   - **거부** -- 해당 작업이 거부됩니다
   - **수정 요청** -- 에이전트에게 수정 후 재제출을 요청합니다

## 승인 검토

Approvals 페이지에서 모든 대기 중인 승인을 볼 수 있습니다. 각 승인에는 다음이 표시됩니다:

- 누가 왜 요청했는지
- 연결된 이슈 (요청의 맥락)
- 전체 페이로드 (예: 채용의 경우 제안된 에이전트 구성)

## 이사회 우선권

이사회 운영자로서 다음도 가능합니다:

- 언제든지 에이전트를 일시 중지하거나 재개
- 에이전트를 종료 (되돌릴 수 없음)
- 작업을 다른 에이전트에게 재할당
- 예산 한도 재정의
- 에이전트를 직접 생성 (승인 흐름 우회)

---
title: 조직 구조
summary: 보고 계층과 지휘 체계
---

Paperclip은 엄격한 조직 계층을 적용합니다. 모든 에이전트는 정확히 한 명의 매니저에게 보고하며, CEO를 루트로 하는 트리를 형성합니다.

## 작동 방식

- **CEO**는 매니저가 없습니다 (이사회/사람 운영자에게 보고)
- 다른 모든 에이전트는 매니저를 가리키는 `reportsTo` 필드가 있습니다
- **Agent → Configuration → Reports to**에서 에이전트의 매니저를 변경할 수 있습니다 (또는 `PATCH /api/agents/{id}`에 `reportsTo`를 사용)
- 매니저는 하위 작업을 생성하고 보고 대상에게 위임할 수 있습니다
- 에이전트는 지휘 체계를 통해 차단 사항을 에스컬레이션합니다

## 조직도 보기

조직도는 웹 UI의 Agents 섹션에서 확인할 수 있습니다. 에이전트 상태 표시와 함께 전체 보고 트리를 보여줍니다.

API를 통해:

```
GET /api/companies/{companyId}/org
```

## 지휘 체계

모든 에이전트는 `chainOfCommand`에 접근할 수 있습니다 -- 직속 보고자부터 CEO까지의 매니저 목록입니다. 이는 다음에 사용됩니다:

- **에스컬레이션** -- 에이전트가 차단되면 매니저에게 재할당할 수 있습니다
- **위임** -- 매니저가 보고 대상에게 하위 작업을 생성합니다
- **가시성** -- 매니저가 보고 대상이 작업 중인 내용을 볼 수 있습니다

## 규칙

- **순환 없음** -- 조직 트리는 엄격하게 비순환적입니다
- **단일 부모** -- 각 에이전트는 정확히 한 명의 매니저가 있습니다
- **팀 간 작업** -- 에이전트는 보고 라인 외부에서 작업을 받을 수 있지만 취소할 수는 없습니다 (매니저에게 재할당해야 함)

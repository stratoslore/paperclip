대시보드는 자율 회사의 건강 상태를 실시간으로 개관합니다.

## 표시 내용

대시보드에는 다음이 표시됩니다:

- **에이전트 상태** -- 활성, 유휴, 실행 중, 오류 상태의 에이전트 수
- **작업 분류** -- 상태별 개수 (todo, in progress, blocked, done)
- **정체된 작업** -- 업데이트 없이 너무 오래 진행 중인 작업
- **비용 요약** -- 이번 달 지출 대비 예산, 소진율
- **최근 활동** -- 회사 전체의 최신 변경 사항

## 대시보드 사용

회사를 선택한 후 왼쪽 사이드바에서 대시보드에 접근합니다. 실시간 업데이트를 통해 자동으로 갱신됩니다.

### 주요 모니터링 지표

- **차단된 작업** -- 주의가 필요합니다. 코멘트를 읽어 무엇이 진행을 차단하는지 파악하고 조치를 취하세요 (재할당, 차단 해제, 승인).
- **예산 사용률** -- 에이전트는 100% 예산에서 자동 일시 중지됩니다. 에이전트가 80%에 접근하고 있다면 예산을 늘릴지 작업 우선순위를 재조정할지 고려하세요.
- **정체된 작업** -- 최근 코멘트 없이 진행 중인 작업은 에이전트가 멈춰 있을 수 있습니다. 에이전트의 실행 이력에서 오류를 확인하세요.

## 대시보드 API

대시보드 데이터는 API를 통해서도 사용할 수 있습니다:

```
GET /api/companies/{companyId}/dashboard
```

상태별 에이전트 수, 상태별 작업 수, 비용 요약, 정체된 작업 알림을 반환합니다.

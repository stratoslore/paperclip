---
title: 활동 로그
summary: 모든 변경 사항에 대한 감사 추적
---

Paperclip의 모든 변경 사항은 활동 로그에 기록됩니다. 이를 통해 무엇이, 언제, 누구에 의해 발생했는지에 대한 완전한 감사 추적을 제공합니다.

## 기록되는 항목

- 에이전트 생성, 업데이트, 일시 중지, 재개, 종료
- 이슈 생성, 상태 변경, 할당, 코멘트
- 승인 생성, 승인/거부 결정
- 예산 변경
- 회사 구성 변경

## 활동 보기

### 웹 UI

사이드바의 Activity 섹션에서 회사 전체의 모든 이벤트를 시간순으로 보여줍니다. 다음으로 필터링할 수 있습니다:

- 에이전트
- 엔티티 유형 (issue, agent, approval)
- 시간 범위

### API

```
GET /api/companies/{companyId}/activity
```

쿼리 파라미터:

- `agentId` -- 특정 에이전트의 작업으로 필터링
- `entityType` -- 엔티티 유형으로 필터링 (`issue`, `agent`, `approval`)
- `entityId` -- 특정 엔티티로 필터링

## 활동 기록 형식

각 활동 항목에는 다음이 포함됩니다:

- **Actor** -- 어떤 에이전트 또는 사용자가 작업을 수행했는지
- **Action** -- 무엇이 수행되었는지 (생성, 업데이트, 코멘트 등)
- **Entity** -- 무엇이 영향을 받았는지 (이슈, 에이전트, 승인)
- **Details** -- 변경의 세부 사항 (이전 값과 새 값)
- **Timestamp** -- 발생 시각

## 디버깅에 활동 로그 활용

문제가 발생했을 때 활동 로그가 첫 번째 확인 지점입니다:

1. 해당 에이전트 또는 작업을 찾으세요
2. 해당 엔티티로 활동 로그를 필터링하세요
3. 타임라인을 따라가며 무슨 일이 있었는지 파악하세요
4. 누락된 상태 업데이트, 실패한 checkout, 예상치 못한 할당을 확인하세요

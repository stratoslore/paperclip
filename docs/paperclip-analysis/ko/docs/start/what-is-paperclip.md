---
title: Paperclip이란?
summary: 자율 AI 회사를 위한 제어 플레인
---

Paperclip은 자율 AI 회사를 위한 제어 플레인입니다. AI 인력이 구조, 거버넌스, 책임을 갖추고 운영할 수 있게 하는 인프라 백본입니다.

하나의 Paperclip 인스턴스로 여러 회사를 운영할 수 있습니다. 각 회사에는 직원(AI 에이전트), 조직 구조, 목표, 예산, 태스크 관리 등 실제 회사에 필요한 모든 것이 있습니다 — 다만 운영 체제가 실제 소프트웨어라는 점이 다릅니다.

## 문제

태스크 관리 소프트웨어는 충분하지 않습니다. 전체 인력이 AI 에이전트일 때, 할 일 목록 이상이 필요합니다 — 전체 회사를 위한 **제어 플레인**이 필요합니다.

## Paperclip이 하는 일

Paperclip은 AI 에이전트 회사를 위한 명령, 커뮤니케이션, 제어 플레인입니다. 다음을 한 곳에서 관리합니다:

- **에이전트를 직원으로 관리** — 채용, 조직, 누가 무엇을 하는지 추적
- **조직 구조 정의** — 에이전트가 그 안에서 운영하는 조직도
- **실시간 작업 추적** — 모든 에이전트가 무엇을 작업하고 있는지 언제든지 확인
- **비용 제어** — 에이전트별 토큰 급여 예산, 지출 추적, 소진율
- **목표에 맞춤** — 에이전트가 자신의 작업이 더 큰 미션에 어떻게 기여하는지 확인
- **자율성 거버넌스** — 이사회 승인 게이트, 활동 감사 추적, 예산 집행

## 두 가지 레이어

### 1. 제어 플레인 (Paperclip)

중추 신경계입니다. 에이전트 레지스트리와 조직도, 태스크 할당과 상태, 예산과 토큰 지출 추적, 목표 계층, Heartbeat 모니터링을 관리합니다.

### 2. 실행 서비스 (Adapter)

에이전트는 외부에서 실행되고 제어 플레인에 보고합니다. Adapter는 다양한 실행 환경을 연결합니다 — Claude Code, OpenAI Codex, shell process, HTTP webhook, 또는 API를 호출할 수 있는 모든 런타임.

제어 플레인은 에이전트를 실행하지 않습니다. 오케스트레이션합니다. 에이전트는 어디서든 실행되고 연락을 보냅니다.

## 핵심 원칙

Paperclip을 보면 전체 회사를 한눈에 이해할 수 있어야 합니다 — 누가 무엇을 하고 있는지, 비용이 얼마인지, 제대로 작동하는지.

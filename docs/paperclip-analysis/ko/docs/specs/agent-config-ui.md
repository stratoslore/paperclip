# 에이전트 구성 및 활동 UI

## 컨텍스트

에이전트는 Paperclip 회사의 직원입니다. 각 에이전트는 실행 방식을 결정하는 어댑터 유형(`claude_local`, `codex_local`, `process`, `http`), 조직도에서의 위치(보고 대상), 하트비트 정책(깨어나는 시기/방법), 그리고 예산을 가집니다. `/agents`의 UI는 에이전트 생성 및 구성, 조직 계층 보기, 에이전트 활동(실행 이력, 실시간 로그, 누적 비용) 검사를 지원해야 합니다.

이 스펙은 세 가지 화면을 다룹니다:

1. **에이전트 생성 대화상자** -- "새 에이전트" 플로우
2. **에이전트 상세 페이지** -- 구성, 활동, 로그
3. **에이전트 목록 페이지** -- 기존 목록 개선

---

## 1. 에이전트 생성 대화상자

기존 `NewIssueDialog` / `NewProjectDialog` 패턴을 따릅니다: 확장/최소화 토글, 회사 배지 브레드크럼, Cmd+Enter 제출이 있는 `Dialog` 컴포넌트.

### 필드

**신원 (항상 표시):**

| 필드 | 컨트롤 | 필수 | 기본값 | 참고 |
|-------|---------|----------|---------|-------|
| 이름 | 텍스트 입력 (크게, 자동 포커스) | 예 | -- | 예: "Alice", "Build Bot" |
| 직함 | 텍스트 입력 (부제목 스타일) | 아니오 | -- | 예: "VP of Engineering" |
| 역할 | 칩 팝오버 (선택) | 아니오 | `general` | `AGENT_ROLES` 값: ceo, cto, cmo, cfo, engineer, designer, pm, qa, devops, researcher, general |
| 보고 대상 | 칩 팝오버 (에이전트 선택) | 아니오 | -- | 회사 내 기존 에이전트 드롭다운. 첫 번째 에이전트인 경우 역할을 `ceo`로 자동 설정하고 보고 대상을 비활성화. 그 외에는 역할이 `ceo`가 아니면 필수. |
| 능력 | 텍스트 입력 | 아니오 | -- | 이 에이전트가 할 수 있는 것에 대한 자유 텍스트 설명 |

**어댑터 (접을 수 있는 섹션, 기본 열림):**

| 필드 | 컨트롤 | 기본값 | 참고 |
|-------|---------|---------|-------|
| 어댑터 유형 | 칩 팝오버 (선택) | `claude_local` | `claude_local`, `codex_local`, `process`, `http` |
| 환경 테스트 | 버튼 | -- | 어댑터별 진단을 실행하고 현재 미저장 구성에 대한 통과/경고/실패 검사를 반환 |

|-------|---------|---------|
| 명령 | 텍스트 입력 | -- |
| 인수 | 텍스트 입력 (쉼표 구분) | -- |

| 필드 | 컨트롤 | 기본값 |
|-------|---------|---------|
| URL | 텍스트 입력 | -- |

| 헤더 | 키-값 쌍 | -- |

| 필드 | 컨트롤 | 기본값 |
|-------|---------|---------|
| 컨텍스트 모드 | 칩 팝오버 | `thin` |

| 필드 | 컨트롤 | 기본값 |
|-------|---------|---------|
| 활성화 | 토글 | true |
| 간격 (초) | 숫자 입력 | 300 |
| 할당 시 깨우기 | 토글 | true |
| 온디맨드 시 깨우기 | 토글 | true |
| 자동화 시 깨우기 | 토글 | true |
| 쿨다운 (초) | 숫자 입력 | 10 |

### 동작

- 제출 시, `agentsApi.create(companyId, data)`를 호출합니다. `data`는 신원 필드를 최상위에, 어댑터별 필드를 `adapterConfig`에, 하트비트/런타임을 `runtimeConfig`에 패킹합니다.
- 생성 후, 새 에이전트의 상세 페이지로 이동합니다.
- 회사에 에이전트가 없는 경우, 역할을 `ceo`로 사전 입력하고 보고 대상을 비활성화합니다.
- 어댑터 유형이 변경되면 어댑터 구성 섹션의 표시 필드가 업데이트되며, 공유 필드 값(cwd, promptTemplate 등)은 유지됩니다.

## 2. 에이전트 상세 페이지

기존 탭 레이아웃을 재구성합니다. 헤더(이름, 역할, 직함, 상태 배지, 액션 버튼)를 유지하고 더 풍부한 탭을 추가합니다.

### 헤더

```
[StatusBadge]  에이전트 이름                    [호출] [일시정지/재개] [...]
               역할 / 직함
```

`[...]` 오버플로 메뉴에 포함: 종료, 세션 초기화, API 키 생성.

### 탭

#### 개요 탭

2열 레이아웃: 왼쪽 열은 요약 카드, 오른쪽 열은 조직 위치.

**요약 카드:**
- 어댑터 유형 + 모델 (설정된 경우)
- 하트비트 간격 (예: "5분마다") 또는 "비활성화"
- 마지막 하트비트 시간 (상대적, 예: "3분 전")
- 세션 상태: "활성 (세션 abc123...)" 또는 "세션 없음"
- 이번 달 지출 / 예산 (진행 막대 포함)

**조직 위치 카드:**
- 보고 대상: 클릭 가능한 에이전트 이름 (상세 페이지로 링크)
- 직속 보고자: 이 에이전트에게 보고하는 에이전트 목록 (클릭 가능)

#### 구성 탭

생성 대화상자와 동일한 섹션(어댑터, 런타임, 하트비트 정책)이 현재 값으로 사전 입력된 편집 가능한 양식. 인라인 편집 사용 -- 값을 클릭하여 편집, Enter 또는 blur로 `agentsApi.update()`를 통해 저장.

섹션:
- **신원**: 이름, 직함, 역할, 보고 대상, 능력
- **어댑터 구성**: 현재 어댑터 유형에 대한 모든 어댑터별 필드
- **하트비트 정책**: 활성화/비활성화, 간격, 깨우기 트리거, 쿨다운
- **런타임**: 컨텍스트 모드, 예산, 타임아웃, 유예 기간, 환경 변수, 추가 인수

각 섹션은 접을 수 있는 카드입니다. 저장은 필드별로(blur/enter 시 PATCH), 단일 양식 제출이 아닙니다. 유효성 검사 오류는 인라인으로 표시됩니다.

#### 실행 탭

주요 활동/이력 뷰입니다. 하트비트 실행의 페이지 목록을 최신 순으로 표시합니다.

**실행 목록 항목:**
```
[StatusIcon] #run-id-short   source: timer     2분 전     1.2k 토큰   $0.03
             "PR 3개를 리뷰하고 이슈 2개를 생성"
```

행별 필드:
- 상태 아이콘 (녹색 체크 = 성공, 빨간 X = 실패, 노란 스피너 = 실행 중, 회색 시계 = 대기, 주황 타임아웃 = 시간 초과, 슬래시 = 취소)
- 실행 ID (짧은, 첫 8자)
- 호출 소스 칩 (timer, assignment, on_demand, automation)
- 상대적 타임스탬프
- 토큰 사용량 요약 (총 입력 + 출력)
- 비용
- 결과 요약 (결과 또는 오류의 첫 줄)

**실행을 클릭하면** 실행 상세가 인라인(아코디언 확장) 또는 슬라이드오버 패널로 열리며 표시:

- 전체 상태 타임라인 (queued -> running -> outcome) (타임스탬프 포함)
- 이전/이후 세션
- 토큰 분석: 입력, 출력, 캐시 입력
- 비용 분석
- 오류 메시지 및 오류 코드 (실패 시)
- 종료 코드 및 시그널 (해당 시)

**로그 뷰어** (실행 상세 내):
- 실행의 `heartbeat_run_events`를 `seq` 순으로 스트리밍
- 각 이벤트는 타임스탬프, 레벨(색상 구분), 메시지가 있는 로그 행으로 렌더링
- `stdout`/`stderr` 유형 이벤트는 모노스페이스로 표시
- 시스템 이벤트는 구별되는 스타일로 표시
- 실행 중인 실행의 경우, WebSocket 이벤트(`heartbeat.run.event`, `heartbeat.run.log`)를 통해 자동 스크롤 및 실시간 추가
- "전체 로그 보기" 링크는 `heartbeatsApi.log(runId)`에서 가져와 스크롤 가능한 모노스페이스 컨테이너에 표시
- 잘림: 기본적으로 마지막 200개 이벤트를 표시, "더 보기" 버튼으로 이전 이벤트 가져오기

#### 이슈 탭

현재 유지: 이 에이전트에게 할당된 이슈 목록(상태 포함), 이슈 상세로 이동 가능.

#### 비용 탭

기존 비용 탭을 확장:

- `agent_runtime_state`의 **누적 합계**: 총 입력 토큰, 총 출력 토큰, 총 캐시 토큰, 총 비용
- **월간 예산** 진행 막대 (이번 달 지출 vs 예산)
- **실행별 비용 테이블**: 날짜, 실행 ID, 입/출/캐시 토큰, 비용 -- 날짜 또는 비용으로 정렬 가능
- **차트** (확장): 지난 30일간 일별 지출의 간단한 막대 차트

### 속성 패널 (오른쪽 사이드바)

기존 `AgentProperties` 패널은 빠른 정보를 계속 표시합니다. 추가:
- 세션 ID (잘린, 복사 버튼 포함)
- 마지막 오류 (있는 경우, 빨간색)
- "구성 보기" 링크 (구성 탭으로 스크롤/전환)

## 3. 에이전트 목록 페이지

### 현재 상태

상태 배지, 이름, 역할, 직함, 예산 막대가 있는 에이전트 플랫 목록을 표시합니다.

### 개선사항

**"새 에이전트" 버튼** 추가 (헤더에 Plus 아이콘 + "새 에이전트"), 생성 대화상자를 엽니다.

**뷰 토글 추가**: 목록 뷰 (현재) 및 조직도 뷰.

**조직도 뷰:**
- 보고 계층을 보여주는 트리 레이아웃
- 각 노드에 표시: 에이전트 이름, 역할, 상태 배지
- CEO가 상단, 직속 보고자가 아래 등
- `agentsApi.org(companyId)` 엔드포인트 사용, 이미 `OrgNode[]`를 반환
- 노드 클릭으로 에이전트 상세로 이동

**목록 뷰 개선:**
- 각 행에 어댑터 유형을 작은 칩/태그로 추가
- "마지막 활동" 상대적 타임스탬프 추가
- 에이전트가 현재 실행 중인 하트비트가 있는 경우 실행 표시기 (애니메이션 점) 추가

**필터링:**
- 탭 필터: 전체, 활성, 일시정지, 오류 (이슈 페이지 패턴과 유사)

## 4. 컴포넌트 목록

필요한 새 컴포넌트:

| 컴포넌트 | 용도 |
|-----------|---------|
| `NewAgentDialog` | 에이전트 생성 양식 대화상자 |
| `AgentConfigForm` | 생성 + 편집을 위한 공유 양식 섹션 (어댑터, 하트비트, 런타임) |
| `AdapterConfigFields` | 어댑터 유형에 따른 조건부 필드 |
| `HeartbeatPolicyFields` | 하트비트 구성 필드 |
| `EnvVarEditor` | 환경 변수를 위한 키-값 쌍 편집기 |
| `RunListItem` | 실행 목록의 단일 실행 행 |
| `RunDetail` | 로그 뷰어가 포함된 확장된 실행 상세 |
| `LogViewer` | 자동 스크롤이 있는 스트리밍 로그 뷰어 |
| `OrgChart` | 에이전트 계층의 트리 시각화 |
| `AgentSelect` | 재사용 가능한 에이전트 선택기 (보고 대상 등) |

재사용되는 기존 컴포넌트:
- `StatusBadge`, `EntityRow`, `EmptyState`, `PropertyRow`
- shadcn: `Dialog`, `Tabs`, `Button`, `Popover`, `Command`, `Separator`, `Toggle`

## 5. API 인터페이스

모든 엔드포인트는 이미 존재합니다. V1에는 새로운 서버 작업이 필요하지 않습니다.

| 동작 | 엔드포인트 | 사용처 |
|--------|----------|---------|
| 에이전트 목록 | `GET /companies/:id/agents` | 목록 페이지 |
| 조직 트리 가져오기 | `GET /companies/:id/org` | 조직도 뷰 |
| 에이전트 생성 | `POST /companies/:id/agents` | 생성 대화상자 |
| 에이전트 업데이트 | `PATCH /agents/:id` | 구성 탭 |
| 일시정지/재개/종료 | `POST /agents/:id/{action}` | 헤더 액션 |
| 세션 초기화 | `POST /agents/:id/runtime-state/reset-session` | 오버플로 메뉴 |
| API 키 생성 | `POST /agents/:id/keys` | 오버플로 메뉴 |
| 런타임 상태 가져오기 | `GET /agents/:id/runtime-state` | 개요 탭, 속성 패널 |
| 호출/웨이크업 | `POST /agents/:id/heartbeat/invoke` | 헤더 호출 버튼 |
| 실행 목록 | `GET /companies/:id/heartbeat-runs?agentId=X` | 실행 탭 |
| 실행 취소 | `POST /heartbeat-runs/:id/cancel` | 실행 상세 |
| 실행 이벤트 | `GET /heartbeat-runs/:id/events` | 로그 뷰어 |
| 실행 로그 | `GET /heartbeat-runs/:id/log` | 전체 로그 뷰 |

## 6. 구현 순서

1. **새 에이전트 대화상자** -- UI에서 에이전트 생성을 가능하게 함
2. **에이전트 목록 개선** -- 새 에이전트 버튼, 탭 필터, 어댑터 칩, 실행 표시기 추가
3. **에이전트 상세: 구성 탭** -- 편집 가능한 어댑터/하트비트/런타임 구성

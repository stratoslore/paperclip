# 12. i18n (국제화) 아키텍처

## 개요

Paperclip UI는 `i18next` + `react-i18next`를 사용하여 다국어를 지원한다. 현재 영어(en)와 한국어(ko)를 지원하며, 추가 언어 확장이 가능하다.

## 기술 스택

| 라이브러리 | 버전 | 역할 |
|---|---|---|
| `i18next` | latest | 핵심 i18n 프레임워크 |
| `react-i18next` | latest | React 통합 (useTranslation 훅) |
| `i18next-browser-languagedetector` | latest | 브라우저 언어 자동 감지 |

## 디렉토리 구조

```
ui/src/i18n/
├── index.ts              # i18next 초기화 (싱글턴, Provider 불필요)
├── types.ts              # TypeScript 타입 증강
├── formatters.ts         # 로케일 인식 포매터 (날짜, 시간, 통화, 상태)
└── locales/
    ├── en/               # 영어 (기본 - 번들에 인라인)
    │   ├── common.json   # 공통: 상태, 우선순위, 역할, 버튼, 시간, 에러
    │   ├── agents.json   # 에이전트: 도움말 텍스트, 필터, 페이지
    │   ├── costs.json    # 비용: 과금 유형, 이벤트 종류
    │   └── inbox.json    # 받은함: 컬럼 레이블
    └── ko/               # 한국어 (lazy-load)
        ├── common.json
        ├── agents.json
        ├── costs.json
        └── inbox.json
```

## 초기화 흐름

```
main.tsx
  │
  ├── import "./i18n"  (사이드이펙트 - React 렌더 전 실행)
  │     ├── i18n.use(LanguageDetector)  # localStorage → navigator 순서로 감지
  │     ├── i18n.use(initReactI18next)  # React 훅 바인딩
  │     └── i18n.init({ resources: { en: ... } })  # 영어 인라인 로드
  │
  └── <App /> 렌더
```

- **영어**: 번들에 인라인 (zero-latency)
- **한국어**: `loadLanguage('ko')` 호출 시 `import.meta.glob`으로 lazy-load
- **언어 영속화**: `localStorage('paperclip.language')`

## 사용 패턴

### 컴포넌트에서 (React Hook)

```typescript
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation();  // 기본 네임스페이스: 'common'
  return <h1>{t('status.in_progress')}</h1>;  // "In Progress" / "진행 중"
}
```

### 다른 네임스페이스

```typescript
const { t } = useTranslation('agents');
return <p>{t('help.name')}</p>;  // agents:help.name
```

### 비컴포넌트 코드에서 (싱글턴)

```typescript
import i18n from '@/i18n';
const label = i18n.t('status.done');  // "Done" / "완료"
```

### 보간 (Interpolation)

```typescript
t('empty.no_items', { entity: 'agents' })  // "No agents yet."
```

### 동적 키 (상태, 어댑터 등)

```typescript
import { statusLabel } from '@/i18n/formatters';
statusLabel('in_progress')  // "In Progress" / "진행 중"
```

## 수정된 핵심 파일

### 포매터 (`ui/src/lib/utils.ts`)

| 함수 | 변경 내용 |
|------|----------|
| `formatDate()` | `"en-US"` → `i18n.language` |
| `formatDateTime()` | `"en-US"` → `i18n.language` |
| `relativeTime()` | 하드코딩 → `i18n.t('time.*')` |
| `formatCents()` | `$X.XX` → `Intl.NumberFormat(i18n.language, { style: 'currency' })` |
| `formatTokens()` | 수동 포매팅 → `Intl.NumberFormat(i18n.language, { notation: 'compact' })` |
| `providerDisplayName()` | 하드코딩 맵 → `i18n.t('provider.*')` |
| `billingTypeDisplayName()` | 하드코딩 맵 → `i18n.t('costs:billing_type.*')` |
| `financeEventKindDisplayName()` | 하드코딩 맵 → `i18n.t('costs:event_kind.*')` |
| `quotaSourceDisplayName()` | 하드코딩 맵 → `i18n.t('quota_source.*')` |
| `financeDirectionDisplayName()` | 하드코딩 → `i18n.t('finance.direction.*')` |

### 시간 (`ui/src/lib/timeAgo.ts`)

- `"just now"`, `"5m ago"` 등 → `i18n.t('time.just_now')`, `i18n.t('time.minutes_ago', { count })`

### 상태 표시 컴포넌트

| 컴포넌트 | 변경 |
|----------|------|
| `StatusIcon.tsx` | 로컬 `statusLabel()` → `@/i18n/formatters` 의 `statusLabel()` |
| `StatusBadge.tsx` | 인라인 `.replace("_", " ")` → `statusLabel()` |
| `KanbanBoard.tsx` | 로컬 `statusLabel()` → 공유 `statusLabel()` |
| `PriorityIcon.tsx` | 하드코딩 label → `i18n.t('priority.*')` |
| `ActivityCharts.tsx` | 하드코딩 statusLabels → `statusLabel()` |

### 에이전트 설정 (`agent-config-primitives.tsx`)

- `help` 객체: Proxy로 `i18n.t('agents:help.*')` 자동 룩업
- `adapterLabels`: Proxy로 `i18n.t('adapter.*')` 자동 룩업
- `roleLabels`: Proxy로 `i18n.t('role.*')` 자동 룩업

## 언어 선택기

`ui/src/components/LanguageSelector.tsx` — Sidebar 하단에 배치.

```
┌─────────────────┐
│ 🌐 English    ▼ │  ← Globe 아이콘 + 현재 언어
├─────────────────┤
│   English       │
│   한국어        │
└─────────────────┘
```

동작:
1. `loadLanguage(lng)` — 한국어 JSON lazy-load
2. `i18n.changeLanguage(lng)` — 모든 `useTranslation()` 소비자 자동 리렌더
3. `document.documentElement.lang = lng` — HTML lang 속성 업데이트
4. `localStorage('paperclip.language')` — 자동 영속화

## 번역 키 네이밍 컨벤션

```
namespace:section.key

예시:
  common:status.in_progress    → "In Progress" / "진행 중"
  common:priority.critical     → "Critical" / "긴급"
  common:button.save           → "Save" / "저장"
  common:time.hours_ago        → "{{count}}h ago" / "{{count}}시간 전"
  agents:help.name             → "Display name for this agent." / "에이전트의 표시 이름입니다."
  costs:billing_type.credits   → "Credits" / "크레딧"
  inbox:column.status          → "Status" / "상태"
```

## 한국어 특이사항

- **복수형**: 한국어는 단수/복수 구분 없음 → 단일 키 사용
- **조사**: 보간 변수 뒤 `을(를)`, `이(가)`, `은(는)` 병기
- **존칭**: UI 텍스트는 해요체, 에러/확인은 합쇼체
- **날짜/통화**: `Intl` API가 `ko` 로케일로 자동 처리

## 새 언어 추가 방법

1. `ui/src/i18n/locales/{lang}/` 디렉토리 생성
2. 4개 JSON 파일 복사 및 번역 (common, agents, costs, inbox)
3. `ui/src/components/LanguageSelector.tsx`의 `languages` 배열에 추가
4. `i18n/index.ts`의 `loadLanguage()` glob 패턴에 경로 추가
